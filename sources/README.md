# Chinese observability and eBPF source corpus

This directory contains local snapshots of Chinese-language source material used to compile the terminology tables. See `source_manifest_2026-09-03_v1.0.0.tsv` in the repository root for URLs, project identities, retrieval dates, and selection notes.

The corpus is intentionally selective: it preserves terminology-dense documentation, blogs, reports, and white papers rather than complete source-code repositories.
